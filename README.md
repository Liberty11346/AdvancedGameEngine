# README

## Unreal Engine Version
- **UE Version:** 5.0.3

## Build / Run Instructions
1. Download **AdvGE_Final_Team_9_Build.zip**.
2. Extract the archive.
3. Run **finalExam.exe**.

## Controls
- **W / A / S / D**: Move
- **Spacebar**: Jump

## Map List
- hjh.umap (Level A, by HwangJuHyeon, 5646281)
- YHMap.umap (Level B, by KimYoungHo, 5646372)
- MapBySeo.umap (Level C, by SeoHyunGyu, 5646125)
- ThirdPersonMap.umap (Level D, by LeeChangMin, 5702600)

## Intended Play Order
The game is intended to be played in the order listed above.  
Players do not need to manually select maps, as they are automatically played in this sequence.
